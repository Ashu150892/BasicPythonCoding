## Python uses the input() function to get information from the user.

## Whatever the user types using input() is stored as a string (str).

## Converting Data Types (Type Casting)

print("5"*3)  --> output 555, 5 will print 3 times        ## string repetition.
print(5*"3")  --> output 33333, 3 will print 5 times      ## string repetition.
print("5"+3)  --> Error because "5" is str and 3 is int
print("5"+"3") --> output 53 both are str.

## In case of numberic value alway use float if you are taking output from user.

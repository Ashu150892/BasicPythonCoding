## Operators are the symbol that help to perform operation between two operands
Type of Operators:
   ## Arithmetic
   ## Comparison
   ## Logical
   ## Assignment

## Arithmetic  (+, -, /, *, //, %, **)
Division '/' return type is flaot even it is whole.  <class 'float'>
Floor Division '//' will return always whole number. Eg: 3.33333 --> 3

## Comparison
-- equal (==)
Return type : bool

-- not equal (!=)
Return type : bool

-- greater than (>)
Return type : bool

-- less than (<)
Return type : bool

-- greater than or equal to (>=)
Return type : bool

-- less than or equal to (<=)
Return type : bool

## Assignment : use to assign value to the variable

   +=
   -=
   /=
   *=

Return type : bool

## Logical (and , or , not)

# Operator    	Meaning
and	        Both conditions must be True
or	           At least one condition must be True
not	        Reverses True/False

Return type : bool

## Scope of Variable:
    Outside Function  ------> Global Variable
    Inside  Function  ------> Local Variable

## Syntax for Global Variable:
    name = "any name"
    def name_display(name):
       print(name)
    name_display()

## Syntax for local Varible:
def name_display()
   name="Amit"
   print(name)
name_display()

## If want to use local variable globally use the concept of return.

# A local variable belongs to the function. A global variable belongs to the outer program
